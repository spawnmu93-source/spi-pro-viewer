# 🥩 Sistema de Producción Integral (SPI)

Repositorio central del Sistema de Producción Integral (SPI) para control de despiece porcino, cría y granja, faena industrial, chacinados y control de stock centralizado.

---

## ⚡ Inicio Rápido

Para iniciar el sistema de manera visual e intuitiva, haz doble clic en:

👉 **`LANZADOR_SPI.bat`** (Abre el Panel Maestro de Control)

O utiliza los lanzadores directos según el área de trabajo:
- **`01_SPI_Despiece_Horizontal.bat`**: Planta de Despiece (Pesaje con Balanza y Combos).
- **`02_SPI_Despiece_Vertical.bat`**: Planta de Despiece (Modo Vertical).
- **`03_Servidor_Web_y_Stock.bat`**: Servidor API FastAPI y Control Web de Stock (`http://localhost:8000`).
- **`04_SPI_Cachorras.bat`**: Módulo de Granja y Genética Porcina.
- **`05_SPI_Frigorifico_Faena.bat`**: Terminal Industrial de Faena (Gancho Aéreo + ZPL).
- **`06_SPI_Fabrica_Despiece.bat`**: Terminal Industrial de Fábrica (Batea Chacinados + Térmico).
- **`07_Diagnostico_Balanza.bat`**: Diagnóstico de Balanzas Digitales Seriales.
- **`08_Ejecutar_Tests_Sistema.bat`**: Verificación y pruebas automáticas de regresión.

Para ver la documentación completa y el detalle de arquitectura, consulta [**MAPA_DEL_SISTEMA.md**](MAPA_DEL_SISTEMA.md).
